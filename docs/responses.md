# HTTP-коды ответов

## Обзор

REST API использует стандартные HTTP-коды состояния для информирования клиента о результате выполнения запроса.

| Код                          | Название            | Когда используется                                                                                                               |
| ---------------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| **200 OK**                   | Успешное выполнение | Запрос успешно обработан, ресурс получен или изменён.                                                                            |
| **201 Created**              | Ресурс создан       | Новый ресурс успешно создан.                                                                                                     |
| **204 No Content**           | Нет содержимого     | Ресурс успешно удалён или операция выполнена без возврата тела ответа.                                                           |
| **401 Unauthorized**         | Не авторизован      | Пользователь не предоставил JWT-токен или токен недействителен.                                                                  |
| **403 Forbidden**            | Доступ запрещён     | Пользователь аутентифицирован, но не обладает необходимыми правами.                                                              |
| **404 Not Found**            | Ресурс не найден    | Запрашиваемый объект отсутствует в системе.                                                                                      |
| **409 Conflict**             | Конфликт данных     | Операция не может быть выполнена из-за конфликта данных (например, создание пользователя с уже существующим логином или e-mail). |
| **422 Unprocessable Entity** | Ошибка валидации    | Переданные данные не соответствуют требованиям API или содержат некорректные значения.                                           |


## Формат ошибок

Большинство ошибок возвращается в следующем формате:

```json
{
    "detail": "Описание ошибки"
}
```


### Ошибки валидации

При ошибке валидации (`422 Unprocessable Entity`) API возвращает список найденных ошибок.

Пример ответа:

```json
{
    "detail": [
        {
            "loc": [
                "body",
                "field"
            ],
            "msg": "Field required",
            "type": "missing"
        }
    ]
}
```
