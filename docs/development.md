# Разработка

## Общая информация

Проект использует **Poetry** для управления зависимостями и виртуальным окружением. Все команды рекомендуется выполнять из корневой директории проекта.

## Архитектура проекта

Проект построен по принципу многослойной архитектуры (Layered Architecture), в которой каждый слой отвечает за отдельную область ответственности. Такой подход упрощает сопровождение, тестирование и дальнейшее развитие приложения.

Взаимодействие компонентов происходит по следующей схеме:

`HTTP Request` -> `API (Routers)` -> `Services` -> `Repositories` -> `Data Base`

### Основные слои приложения:

- API (Routers) - обработка HTTP-запросов, валидация входных данных и формирование ответов.
- Services - реализация бизнес-логики приложения. Здесь принимаются основные решения и выполняются проверки и валидация.
- Repositories - взаимодействие с базой данных и выполнение CRUD-операций.
- Models - SQLAlchemy-модели, описывающие структуру данных.
- Schemas - Pydantic-модели для валидации запросов и сериализации ответов.
- Core - общие компоненты приложения: конфигурация, безопасность, JWT-аутентификация и вспомогательные функции.

Каждый слой зависит только от нижележащего слоя, что позволяет минимизировать связанность компонентов и облегчает их тестирование и повторное использование.

## Виртуальное окружение

Poetry **автоматически** создает виртуальное окружение при установке зависимостей.

При необходимости его можно активировать вручную:

### Windows (PowerShell)

```powershell
.venv\Scripts\Activate.ps1
```

### Windows (CMD)

```cmd
.venv\Scripts\activate.bat
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Для выхода из виртуального окружения:

```bash
deactivate
```

> При использовании `poetry run` ручная активация виртуального окружения **не требуется**.

## Форматирование и анализ кода

Перед отправкой изменений рекомендуется выполнить форматирование и проверку качества кода.

### Форматирование (Black)

```bash
poetry run black app/
```

### Проверка стиля (Flake8)

```bash
poetry run flake8 app/
```

## Управление зависимостями

### Добавление зависимости приложения

```bash
poetry add <package>
```

### Добавление зависимости для разработки

```bash
poetry add --group dev <package>
```

### Удаление зависимости приложения

```bash
poetry remove <package>
```

### Удаление зависимости для разработки

```bash
poetry remove --group dev <package>
```

Все изменения зависимостей автоматически отражаются в файлах:

* `pyproject.toml`;
* `poetry.lock`.

## Работа с PostgreSQL

Для подключения к PostgreSQL внутри Docker-контейнера можно воспользоваться командой:

```bash
docker exec -it reservation-app-db psql -U postgres -d reservation-app-db
```

После подключения становятся доступны стандартные команды PostgreSQL. Например:

- просмотр всех таблиц - `\dt`
- просмотр содержимого таблицы пользователей - `SELECT * FROM users;`
- выход из консоли PostgreSQL - `\q`
