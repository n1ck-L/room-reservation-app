# Тестирование

## Общая информация

Для тестирования проекта используется **Pytest**. Все тесты располагаются в директории `tests/`.

Конфигурация Pytest определена в файле `pyproject.toml` и включает:

* поиск тестов в директории `tests`;
* подробный вывод результатов (`-v`);
* режим импорта `importlib`, исключающий конфликты импортов.

## Запуск тестов

### Запуск всех тестов

```bash
poetry run pytest
```

### Запуск тестов по метке

Для запуска определённой группы тестов используется параметр `-m`:

```bash
poetry run pytest -m <имя_метки>
```

Например:

```bash
poetry run pytest -m unit
```

или

```bash
poetry run pytest -m reservation_service
```

## Доступные метки

### Общие

| Метка  | Описание                |
| ------ | ----------------------- |
| `unit` | Все юнит-тесты проекта. |

### Сервисный слой (Business Logic)

| Метка                 | Описание                             |
| --------------------- | ------------------------------------ |
| `service`             | Все тесты сервисного слоя.           |
| `user_service`        | Сервис пользователей.                |
| `room_service`        | Сервис переговорных комнат.          |
| `reservation_service` | Сервис бронирований.                 |
| `auth_service`        | Сервис аутентификации и JWT-токенов. |

### API (Роутеры)

| Метка                | Описание                                        |
| -------------------- | ----------------------------------------------- |
| `router`             | Все тесты API-эндпоинтов.                       |
| `user_router`        | Эндпоинты управления пользователями.            |
| `room_router`        | Эндпоинты управления комнатами.                 |
| `reservation_router` | Эндпоинты управления бронированиями.            |
| `auth_router`        | Эндпоинты аутентификации и управления токенами. |

### Репозитории

| Метка                    | Описание                                        |
| ------------------------ | ----------------------------------------------- |
| `repository`             | Все тесты слоя доступа к данным.                |
| `user_repository`        | Репозиторий пользователей (`users`).            |
| `room_repository`        | Репозиторий переговорных комнат (`rooms`).      |
| `reservation_repository` | Репозиторий бронирований (`reservations`).      |
| `token_repository`       | Репозиторий refresh-токенов (`refresh_tokens`). |

## Примеры

Запустить все тесты сервисного слоя:

```bash
poetry run pytest -m service
```

Запустить только тесты пользователей:

```bash
poetry run pytest -m user_service
```

Запустить только тесты API бронирований:

```bash
poetry run pytest -m reservation_router
```

Запустить только тесты репозитория комнат:

```bash
poetry run pytest -m room_repository
```

## Рекомендации

* Перед запуском тестов убедитесь, что все зависимости проекта установлены с помощью `poetry install`.
* Для тестов, взаимодействующих с базой данных, убедитесь, что PostgreSQL запущена и параметры подключения соответствуют значениям в файле `.env`.
* При добавлении новых тестов рекомендуется использовать существующие маркеры либо зарегистрировать новые в разделе `tool.pytest.ini_options.markers` файла `pyproject.toml`.
